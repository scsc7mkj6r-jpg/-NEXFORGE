# NEXFORGE — Weapon System

## Core Features
- Multiple weapon categories
- Weapon switching
- Reloading system
- Ammunition counter
- Weapon animations
- Mobile shooting controls

## Weapon Categories
- Assault rifles
- Submachine guns
- Shotguns
- Sniper rifles
- Pistols

## Gameplay Rules
- Each weapon has different game balance statistics.
- Players can select equipment before a match.
- Ammunition is limited during matches.

## Future Features
- Weapon customization
- Skins and cosmetics
- Equipment loadouts
- Weapon progression
